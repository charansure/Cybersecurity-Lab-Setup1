## 📌 Project Overview

This project is part of my **Cybersecurity Internship at Networkwalks (Batch B082)**.

The objective of this task was to build and configure a virtual cybersecurity testing environment using Oracle VirtualBox and Kali Linux.

The lab provides a controlled environment for learning cybersecurity concepts, networking, and penetration testing fundamentals.

## 🎯 Objectives

- Install and configure Oracle VirtualBox.
- Import and configure Kali Linux.
- Create a private NAT Network.
- Configure and verify network settings.
- Test network connectivity and DNS resolution.
- Create a clean virtual machine snapshot for recovery.

## 🛠️ Tools & Technologies Used

| Tool | Purpose |
|---|---|
| Oracle VirtualBox | Virtualization platform |
| Kali Linux | Cybersecurity operating system |
| NAT Network | Virtual network configuration |
| Linux Terminal | Network configuration and testing |

## ⚙️ Tasks Completed

### 1. VirtualBox Installation

Installed and configured Oracle VirtualBox to create and manage virtual machines.

### 2. Kali Linux Setup

Imported the Kali Linux virtual machine into VirtualBox and completed the initial configuration.

### 3. NAT Network Configuration

Created a private NAT Network in VirtualBox and connected the Kali Linux virtual machine to it.

### 4. Network Configuration Verification

Verified the network configuration using Linux terminal commands.

Commands used:

```bash
ip addr
ip route
```

### 5. Network Connectivity Testing

Tested internet connectivity using:

```bash
ping -c 4 8.8.8.8
```

### 6. DNS Resolution Testing

Verified DNS resolution using:

```bash
ping -c 4 google.com
```
## 📚 Key Learnings

Through this hands-on project, I learned:

- Fundamentals of virtualization and virtual machines.
- Differences between NAT and NAT Network.
- Kali Linux installation and configuration.
- IP addressing and network configuration.
- Network connectivity and DNS resolution testing.
- Importance of virtual machine snapshots and recovery.
- Technical documentation and lab management.

## 🔒 Learning Environment

All configurations and activities were performed in a local virtual lab environment for educational and cybersecurity training purposes.
